# Learn Trailhead MCP

A step-by-step demo site and written guide for **Trailhead MCP**, the free Model Context Protocol server that lets AI assistants search and read Trailhead badges and trails.

**Server endpoint:** `https://mcp.trailhead.salesforce.com/mcp`

## Steps

Each step is added on its own branch and merged through a pull request.

| # | Step | Section | Doc |
|---|------|-----------|-----|
| 1 | Intro & overview | `#intro` | [docs/01-intro-overview.md](docs/01-intro-overview.md) |
| 2 | Hands-on with supported clients | `#clients` | [docs/02-supported-clients.md](docs/02-supported-clients.md) |
| 3 | Client: Agentforce | `#clients` → Agentforce | [docs/03-agentforce.md](docs/03-agentforce.md) |

## Repo layout

```
site/index.html    Demo site: one page, one <section> per step
site/assets/       Shared styles.css and app.js; clients.js holds client data
docs/              Markdown write-up for each step
```

Content is based on the Trailhead MCP Guide at <https://trailhead.salesforce.com/support/mcp>. Check it for the latest steps.
